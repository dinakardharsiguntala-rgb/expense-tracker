100% Auto-SMS on iPhone

Apple restricts all third-party apps from reading SMS directly. But Apple built an official tool called Shortcuts Automation that automatically forwards bank messages into this app!

1

Open the "Shortcuts" App on iPhone

Shortcuts comes pre-installed on every iPhone. Open it and tap the Automation tab at the bottom.

2

Create New Automation → Message

Tap + → select Message. In "Message Contains", enter keywords:

debited, spent, credited, paid, INR, Rs

Select "Run Immediately" (no prompt needed!).

3

Add Action: Open Web App with Text

Add action "Open URLs" and set URL to:

https://dinakardharsiguntala-rgb.github.io/expense-tracker/?sms=[Shortcut Input]
