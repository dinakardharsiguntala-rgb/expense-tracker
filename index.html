100% Auto-SMS on iPhone

Important: Apple Shortcuts only triggers for NEW incoming messages received from now on. Apple prohibits all shortcuts and apps from reading past/existing SMS history. (To add past messages, use the paste box on the Bank SMS tab!).
⚡ 1-Tap: Open Shortcuts App
1

Open "Shortcuts" App → Automation Tab

Open Apple's pre-installed Shortcuts app and tap the Automation tab at the bottom.

2

Create New Automation → "Message"

Tap + → choose Message. In "Message Contains", enter keywords:

debited, spent, credited, paid, INR, Rs

Select "Run Immediately" (so it runs automatically without asking).

3

Add Actions (Choose Either Method)

Method A (Recommended):

Add action "Copy to Clipboard" (Input: Shortcut Input), then add action "Open URLs" with:

https://dinakardharsiguntala-rgb.github.io/expense-tracker/

Method B (Direct URL Parameter):

Add action "URL Encode" (Input: Shortcut Input), then add "Open URLs" with:

https://dinakardharsiguntala-rgb.github.io/expense-tracker/?sms=[URL Encoded Text]
